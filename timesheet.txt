## 2. Dataverse Tables & Exact Column Definitions

### A. Project Table
**Schema name:** `crb_project`

| Display Name | Schema Name | Type | Notes |
|-------------|------------|------|------|
| Project Name | crb_name | Text (100) | Required |
| Project Code | crb_projectcode | Text (50) | Optional |
| Active | crb_active | Yes/No | Default: Yes |

---

### B. Pay Period Table
**Schema name:** `crb_payperiod`

| Display Name | Schema Name | Type | Notes |
|-------------|------------|------|------|
| Name | crb_name | Text (100) | e.g., 2025 Jan 1–15 |
| Start Date | crb_startdate | Date Only | Required |
| End Date | crb_enddate | Date Only | Required |
| Status | crb_status | Choice | Open, Locked |

---

### C. Timesheet (Header)
**Schema name:** `crb_timesheet`

> **Business Rule:** Only **one Timesheet per Employee per Pay Period**. Submission is **disabled until Pay Period End Date**.

| Display Name | Schema Name | Type | Notes |
|-------------|------------|------|------|
| Employee | crb_employee | Lookup (System User) | Required |
| Supervisor | crb_supervisor | Lookup (System User) | Derived |
| Pay Period | crb_payperiod | Lookup | Required |
| Status | crb_status | Choice | Draft, Ready to Submit, Submitted, Approved, Correction Requested, Resubmitted, Re-Approved |
| Submitted On | crb_submittedon | DateTime | Set only after period ends |
| Approved On | crb_approvedon | DateTime | Set by approval |
| Current Version | crb_version | Whole Number | Default: 1 |
| Total Hours | crb_totalhours | Decimal (2) | Calculated/Rollup |

**Alternate Key (Enforced Uniqueness):**
- Employee + Pay Period

-------------|------------|------|------|
| Employee | crb_employee | Lookup (System User) | Owner of timesheet |
| Supervisor | crb_supervisor | Lookup (System User) | Derived from user |
| Pay Period | crb_payperiod | Lookup | Required |
| Status | crb_status | Choice | Draft, Submitted, Approved, Correction Requested, Resubmitted, Re-Approved |
| Submitted On | crb_submittedon | DateTime | Set by flow |
| Approved On | crb_approvedon | DateTime | Set by flow |
| Current Version | crb_version | Whole Number | Default: 1 |
| Total Hours | crb_totalhours | Decimal (2) | Rollup or calculated |

## 4. Key Business Rules (Critical)

1. **One Timesheet per Employee per Pay Period**
   - Enforced via Dataverse Alternate Key

2. **Daily Save Allowed**
   - Timesheet remains in Draft during pay period

3. **Submission Locked Until Period End**
   - Submit button enabled only when:
     - Today > PayPeriod.EndDate
     - Status = Draft or Ready to Submit

4. **No Editing After Submission**
   - Except via Correction workflow
